# 🕊️ ギャンブル断ちトラッカー / Gamble-Free Tracker

ギャンブルから離れる毎日を記録し、**衝動が来たその瞬間を乗り切る**ためのモバイルファーストなWebアプリ（PWA）です。
サーバー不要・登録不要で、記録はすべて端末のブラウザ（localStorage）にだけ保存されます。

姉妹アプリ（禁酒・節酒・禁煙）と同じ土台で作っていますが、**ギャンブル依存は他の3つとは性質が違う**ため、
いくつかの機能を意図的に足し、いくつかを意図的に外しています（詳しくは「設計の判断」）。

---

## 🌏 多言語対応

日本語 / English に対応。端末の言語から自動判定し、設定でいつでも切り替えられます。
金額は 円 / ドル / ユーロ / ポンド / ウォン から選べます（自動両替はしません）。

## 主な機能

### 衝動を乗り切る（このアプリの中心）
- **「いま、やりたい気持ちが来た」ボタン** — ホームの最上段と、画面下の常時表示ボタンの2か所から1タップ
- 3分 / 10分 / 20分 のタイマーと呼吸ガイド。20秒ごとに「今できること」が切り替わる
- 自分で書いた「やめる理由」がその場に表示される
- 終わったら「乗り切れましたか？」と聞き、**乗り切った回数が実績として積み上がる**
- タイマー画面から相談窓口へ直接飛べる

### 環境を変える安全策
意志より環境のほうが効く、という考え方に基づいたチェックリスト（8項目）。
アプリの削除、自己申告・家族申告プログラム、カードを預ける、現金・振込の上限、借入の書き出し、
打ち明ける相手、相談窓口への連絡。ホームに達成度が出ます。

### 相談できる窓口
精神保健福祉センター、GA（ギャンブラーズ・アノニマス）、こころの健康相談統一ダイヤル、
よりそいホットライン、消費者ホットライン（188）、法テラス。
**番号はタップでそのまま発信**でき、危機時の案内はシートの最上部に固定しています。

### 継続の見える化
- 継続日数のリング／通算日数／最長記録／乗り切った回数
- 使わずに済んだお金が貯まっていく**貯金箱のイラスト**（ごほうびを設定するとそこが満杯の目安になる）
- 直近7日のストリップ（曜日＋日付）、カレンダー、9段階のバッジ

### 毎日の記録
- 気分（5段階）／やりたい気持ちの強さ（0〜10）／きっかけ（10種類）／自由メモ
- **やってしまった日**は、使った金額と「取り返そうとして続けたか（深追い）」まで記録できる
- 記録直後は取り消せる。連続日数だけがリセットされ、通算の記録は消えない

### 統計
気分とやりたい気持ちの推移（14日）、よくあるきっかけ、乗り切った回数、
やってしまった日の合計金額。

### 続けるための仕掛け
- 日数に合わせて内容が変わる「今日のメッセージ」（年齢を入れると調整されます）
- 日付ごとに決まっている「今日のひとこと」
- ごほうび貯金、毎日のリマインダー通知、実績のシェア画像

### アプリとしての完成度
ホーム画面に追加してオフラインで動作、ダーク/ライトテーマ、端末の「戻る」でシートを閉じる、
バックアップの保存と復元、機種変更の手順、日付またぎの自動更新。

## ⚖️ 設計の判断（姉妹アプリとの違い）

このアプリでは、姉妹アプリにある機能を**2つ意図的に外しています**。

### 1. タロット占い（毎日のランダム抽選）を入れていない

姉妹アプリには「毎日1枚めくると★1〜★5が出て、まれに大吉が出る」という要素があります。
これは**いつ当たるか分からない報酬（変動報酬）そのもの**で、スロットやパチンコを続けさせている
仕組みとまったく同じ構造です。ギャンブルをやめようとしている人に、毎日それを練習させる形になるため、
このアプリには入れていません。

代わりに置いたのが「今日のひとこと」です。**日付から内容が決まる**ため、何度開いても、
引き直しても同じ内容になります。毎日変わる楽しみは残しつつ、抽選の要素だけを外しています。

### 2. 「特別な日」の例外機能を入れていない

姉妹アプリには「結婚式など、事前に決めた特別な日は継続日数が途切れない」という機能があります。
お酒であれば妥当な設計ですが、ギャンブルでは**「今日は特別だから1回だけ」が最も多い再開の入口**です。
アプリの側からその抜け道を用意すべきではないと判断し、外しています。

## 使い方

### ローカルで動かす

```bash
python3 -m http.server 8000
# → ブラウザで http://localhost:8000 を開く
```

### テスト

```bash
# サーバーを起動した状態で
python3 -m http.server 8130 &
npm test
```

Playwright による E2E スモークテスト（110項目以上）が走ります。
「ランダム抽選のUIが存在しないこと」「例外日の機能が存在しないこと」も
設計判断が崩れていないかの回帰テストとして検査しています。

### 静的解析

```bash
npm run lint          # ESLint
npm run stamp-sw      # sw.js のキャッシュ名を中身のハッシュで更新
npm run stamp-sw:check
```

アセットを変更したら `npm run stamp-sw` を必ず実行してください（更新が利用者に届かなくなります）。

## プライバシー

記録はこの端末のブラウザ内にのみ保存されます。外部サーバーへの送信は一切ありません。
アカウント登録も不要です。ブラウザのデータを削除すると記録も消えるため、
ときどき設定からバックアップを保存してください。
